# SC Tools 功能规划与优化建议

> 基于 V3.0（PySide6 重构版）现状整理。按「投入小见效快 → 大功能」排序，每条标注大致工作量。

## 一、建议优先做（投入小、体验提升明显）

### 1. 工具快速搜索 / 命令面板 ★★★★★
侧边栏或 `Ctrl+K` 唤起搜索框，按名称（含拼音首字母，如 `bg` → 坏点检测）实时过滤所有工具和网站卡片，回车直接启动。
工具数量超过 50 个后这是刚需，也是各类启动器（Listary/uTools）的核心体验。

### 2. 最近使用 + 使用频率排序 ★★★★
记录每次启动（已有运行状态监测的钩子），首页顶部加「最近使用」一行；可选「按使用频率排序」开关。数据就存 skin.json 或单独 usage.json。

### 3. 拖拽添加工具 ★★★★
把 exe 直接拖到主窗口 → 弹确认 → 自动生成卡片（名称取文件名、分类可选、图标用现成的 file_icon）。目前加新工具要手动填路径，这是最大的录入摩擦点。

### 4. 托盘图标与关闭行为 ★★★★
最小化/关闭时缩到托盘（可设置），托盘菜单：显示主窗口 / 全局热键提示 / 退出。工具箱类软件常驻后台更顺手。注意与「启动图只在真实冷启动显示」配合。

### 5. 管理员运行 / 右键增强 ★★★
部分工具（注册表类、DiskGenius 等）需要管理员权限。卡片右键菜单加「以管理员身份运行」+「复制路径」，用 ShellExecute "runas" 实现即可。

### 6. 全局异常捕获与日志 ★★★★
`sys.excepthook` 接管未捕获异常，写 `%LOCALAPPDATA%\SCTools\logs\yyyy-mm-dd.log`（含版本号、堆栈），弹一次友好提示。目前崩溃只能靠控制台，用户侧发生的问题无法追溯——之前 UnboundLocalError 就是典型。

## 二、中期功能（值得规划）

### 7. 更多内置小工具
沿用 screen_test 的内置模式（`builtin://` 协议已就绪），成本低、无第三方依赖风险：
- **颜色拾取器**：全局取色（Pickr 思路，QScreen.grabWindow 实现）
- **窗口置顶/透明度调节**：快捷键 + 目标窗口
- **屏幕标尺 / 截图标尺**
- **hosts 编辑器**（需管理员，带备份）
- **DNS 一键切换**（114/223.5.5.5/自定义）
- **右键菜单管理**（清理软件残留项）
- **快速笔记 / 剪贴板历史**

### 8. 配置原子写入与备份
现在 json 是直接覆写。改为「写临时文件 → 替换」，并在每次保存前保留上一份 `.bak`。此前发生过配置被运行中的程序意外重置，这个加固能兜底。

### 9. 便携模式
检测 exe 同目录是否存在 `portable.flag`：存在则配置/缓存全部存本地目录而不是 %LOCALAPPDATA%，配合绿色版分发（装在 U 盘也能带走全部设置）。

### 10. 网站导航增强
- 分组折叠与拖拽排序（目前顺序固定）
- 导入浏览器书签（Chrome/Edge 的 Bookmarks json，按文件夹映射分组）
- 卡片悬停显示 URL 完整地址

### 11. 自动更新加固
- 安装包发布时附 SHA256，更新器下载后校验再执行（防传输损坏/劫持）
- 更新日志在更新确认弹窗里展示（解析 GitHub Release body）
- 支持 `/S` 静默安装参数，方便以后脚本化部署

### 12. 使用统计页
在检查页或设置里加一个简单统计：启动次数、最常用工具 Top10、累计使用天数。纯本地数据，给人「这个工具我离不开」的感知。

## 三、工程与性能优化

| 项 | 现状 | 建议 |
|---|---|---|
| 单实例互斥 | 无，可重复启动多个 | QSharedMemory 锁；二次启动时唤起已有窗口 |
| 启动速度 | 全部页面同步构建 | Tab 页惰性构建（首次切入再建），主窗口出现更快 |
| favicon 抓取 | 后台线程 | 限制并发（QThreadPool maxThreadCount=4），失败域名本地黑名单避免反复重试 |
| 图标缓存 | 无预热 | 安装后首次启动后台预生成，避免首刷卡顿 |
| 安装包体积 | 362MB（tools 占大头） | tools 无法压缩太多；可把「不常用大件」（Ventoy/DirectX Repair）改为首启可选下载 |
| 代码组织 | main_window / settings_page 较大 | 拆分：settings_page 按分区拆 mixin；hotkey 录制、更新检查独立模块 |
| 高分屏 | 依赖 Qt 自动 | 检查 150%/200% 缩放下标题栏与卡片布局，必要时按 devicePixelRatio 调整图标尺寸 |
| 多显示器 | 启动图/主窗口只认主屏 | 记住上次所在屏幕并居中该屏 |

## 四、收尾事项（发版前必须处理）

1. **git 提交**：右键菜单透明度、坏点检测 UI、导航占满布局、favicon 同步、启动图功能、tools 目录整理——全部未提交。
2. **重新打包**：当前安装包 362MB 为旧版，不含上述任何修复；含 3 张启动图后约 390MB。
3. **updater.py 的 REPO 占位**：`Z1321/SCTools` 需改为实际 GitHub 仓库，否则自动更新不可用。
4. **README / 更新日志**：仓库公开后需要一份像样的 README（截图 + 功能列表 + 下载链接）。

## 五、不建议现在做的

- **QtWebEngine（内嵌浏览器）**：体积 +150MB，违背工具箱轻量定位。
- **插件市场/在线脚本**：涉及安全审核机制，单人维护成本过高，先把内置工具做扎实。
- **配置云同步**：需要后端账号体系，用「配置导入导出」手动迁移已够用。
