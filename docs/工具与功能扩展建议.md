## 二、程序功能扩展建议（按优先级）

### P0 — 直接提升日常使用
1. **最近使用 / 收藏**：记录启动历史，侧边栏加「最近使用」与「收藏」入口
2. **拖入扫描批量导入**：把一个文件夹拖到窗口，自动扫描其中所有 exe 批量添加应用
3. **应用启动参数**：编辑对话框加「启动参数」字段（部分工具需要 `-portable` 之类）
4. **窗口状态记忆**：记住上次窗口位置/尺寸/最大化和当前页面

### P1 — 体验增强
5. **应用快捷键**：给常用应用绑定全局热键（如 Ctrl+Alt+1 直接启动）
6. **工具分类重命名/合并**：目前分类固定，支持右键重命名、删除空分类
7. **图标缓存持久化**：若恢复显示程序图标，把提取的图标缓存到 resources/icon_cache 避免重复提取
8. **皮肤方案导入导出**：一键打包 skin.json + 背景图分享
9. **单实例互斥**：防止重复启动两个 SC Tools
10. **配置自动备份**：tools.json 每次保存前留 .bak，防手滑

### P2 — 进阶
11. **应用更新检查**：对内置工具记录版本号，联网检查官网新版本
12. **资源监视小部件**：标题栏/悬浮窗显示 CPU/内存占用（需 psutil）
13. **配置检测定时任务**：启动时静默扫描失效路径并在侧边栏标记角标
14. **多语言 UI**（zh-CN / en）
15. **工具便携化检查**：检测目标目录是否含注册表写入类工具并提示

## 三、打包与体积

- 当前 onedir + tools 复制约 600MB；如需瘦身可做「下载版」：不含 tools，首次使用时按需从本地资源包解压
- UPX 对 PySide6 的 Qt6.dll 压缩收益有限且可能触发误报，可考虑只压缩 python313.dll 与自身代码
